## 1. 문제 정의 및 배경

제조 현장의 품질 관리는 크게 두 축으로 나뉜다 — 회전 설비(엔진 등)의 **고장분석**은
**진동 신호**로, 생산라인 결과물의 **불량 검사**는 **머신비전(열화상 이미지)**으로 이뤄진다.
이 프로젝트는 이 두 이종 신호를 하나의 AI Agent가 함께 모니터링하여, 개별 판단 → 종합 리포트
→ 조치 제안까지 자동화하는 것을 목표로 한다.

- **고장분석**: Ford 엔진 진동 데이터셋 + 회전기계 고장유형 데이터셋 (1D CNN, 진동 시계열)
- **불량검사**: 열화상 이미지를 활용한 머신비전 데이터 (2D CNN, 이미지)

핵심 메시지: **"설비 고장분석과 제품 불량검사를 하나의 Agent가 함께 감시한다."**

## 2. 데이터셋

### (A) 고장분석용 — 진동 데이터

#### 2-1. Ford Engine (KAMP DATASET_SEQ=2)
- 출처: IEEE World Congress on Computational Intelligence 2008 경진대회 데이터 (자동차 서브시스템 진단)
- 형식: 1차원 시계열, 길이 500 (엔진 소음 측정값)
- 규모: Train 3,601개 / Test 1,320개
- 라벨: 이진 분류 (증상 있음/없음), 클래스 비율 균형적 (Train 기준 약 51:49)
- 파일: `FordA_TRAIN.arff`, `FordA_TEST.arff` (CSV 형태 내장)

#### 2-2. 회전기계 고장유형 AI 데이터셋
- 출처: [KAMP 제조AI데이터셋](https://www.kamp-ai.kr/aidataList?AI_SEARCH=&page=1&DATASET_SEQ=&DISPLAY_MODE_SEL=CARD&EQUIP_SEL=&GUBUN_SEL=&FILE_TYPE_SEL=&WDATE_SEL=) — 고장 분석 및 진단을 위한 회전 설비의 진동데이터
- 로컬 파일: `Dataset_회전기계 고장유형 AI 데이터셋.zip`
- 구성: g1/g2 그룹 × 센서 1~4, 총 8개 CSV (`g1_sensor1.csv` ~ `g2_sensor4.csv`)
- 형식: 헤더 없는 시계열, 4개 컬럼(시간 + 진동축 3개 추정), 약 190,218행/파일, 샘플링 간격 0.000736초(≈1.36kHz)
- 활용 목적: Ford Engine 진동 데이터와 함께 회전 설비의 **고장 유형 분석**에 사용
- TODO: g1/g2 그룹 및 sensor1~4의 정확한 고장유형 라벨 매핑은 KAMP 데이터셋 설명서 확인 필요

### (B) 불량검사용 — 머신비전 이미지

#### 2-3. Machine Vision (KAMP DATASET_SEQ=6)
- 형식: 2차 공정 좌/우 라인 표면 프로파일의 시각화 이미지 (jpg, 320×256, jet 컬러맵 — 열화상 형태)
- **결과물 불량 검사는 이 열화상풍 이미지를 머신비전(2D CNN) 입력으로 사용**
- 라벨: OK(양품) / NG(불량) 이진 라벨
  - Right 라인: 422 샘플 (양품 333 / 불량 90 → 불량 비율 약 21%)
  - Left 라인: 413 샘플 (양품 283 / 불량 131 → 불량 비율 약 32%)
- 참고: 동일 폴더에 80포인트로 다운샘플링된 수치 프로파일 CSV(`2nd_process_right/left_data.csv`+`_label.json`)도 있으나, 이번 계획에서는 이미지 기반 머신비전 모델을 사용
- **클래스 불균형 대응 필요** (class weight 또는 오버샘플링)

## 3. 시스템 아키텍처 (Perceive → Reason → Act)

```
[고장분석] Ford Engine 진동  ──┐
                              ├─▶ [1D CNN 고장분석 모델 ×2, 백본 공유] ──▶ 고장 판단(정상/이상+신뢰도) ──┐
          회전기계 진동     ──┘                                                                          │
                                                                                                          ├─▶ [LLM Reasoning]
[불량검사] 열화상 이미지(머신비전) ─────────▶ [2D CNN 불량검사 모델] ──▶ 불량 판단(양품/불량+신뢰도) ──┘      종합 판단 및
                                                                                                       근거 설명 생성
                                                                                                          │
                                                                                                          ▼
                                                                                   [Act] 정비/품질 리포트 자동 생성
                                                                                        + Tool Call (Slack/이메일 mock 알림)
```

- **Perceive**: 고장분석(진동, 1D CNN 백본 공유 ×2) + 불량검사(열화상 이미지, 2D CNN) — 두 트랙을 병렬로 처리
- **Reason**: 두 트랙의 출력(클래스+확률)을 LLM에 전달 → 설비 고장 여부와 제품 불량 여부를 종합 판단 및 근거 설명 생성
- **Act**: 판단 결과 기반 정비/품질 리포트 자동 작성 + 알림 Tool Call (mock 가능)
- **Memory/Feedback**: 과거 판단 이력 로그 저장 → 리포트에 "최근 이상 발생 추이" 포함 (간단한 CSV/SQLite 로그로 구현)

## 4. 모델 설계

### 4-1. 고장분석 모델 (진동, 1D CNN)

| 구분 | Ford Engine | 회전기계 고장유형 |
|---|---|---|
| 입력 | 500포인트 시계열 | 진동 시계열 (windowing 필요) |
| 구조 | 1D CNN (Conv1D + BatchNorm + GAP) | 동일 구조, 입력 길이만 상이 |
| 출력 | 이진 (정상/이상) | 고장유형 분류 (라벨 매핑 확인 후 확정) |
| 불균형 처리 | 불필요 (균형) | 확인 필요 |
| 프레임워크 | PyTorch | PyTorch |

두 모델은 동일한 1D CNN 백본 코드를 재사용하고 입력 길이·출력 클래스만 다르게 설정 → 개발 공수 절감.

### 4-2. 불량검사 모델 (머신비전, 2D CNN)

| 구분 | Machine Vision (좌/우) |
|---|---|
| 입력 | 열화상풍 이미지 (jpg, 320×256, jet 컬러맵) |
| 구조 | 2D CNN (경량 backbone, 예: 간단한 Conv 스택 또는 사전학습 모델 fine-tuning) |
| 출력 | 이진 (양품/불량) |
| 불균형 처리 | Class Weight 적용 |
| 프레임워크 | PyTorch |
